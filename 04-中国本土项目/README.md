## 🚀 快速开始

### 运行 Vue 项目
```bash
cd ChinaVis  # 或 beijing-hangzhou-canal-history-modernity
npm install
npm run serve
```

### 运行 Python 项目
```bash
cd paleolithic-ruins-map
pip install -r requirements.txt
python manage.py migrate
python manage.py runserver
```

### 运行 HTML 项目
```bash
cd ancient-china-map
python -m http.server 8000
```

### 运行 Kotlin 项目
```bash
cd fangguwiki
# 使用 Android Studio 或 IntelliJ IDEA 打开
```
