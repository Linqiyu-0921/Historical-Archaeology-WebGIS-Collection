# 🗺️ Historical Archaeology WebGIS Collection
🗺️🏛️📜 这是一个历史考古与 WebGIS 相关的学习资料收藏夹 —— 像是把时空折叠进硬盘，让古老的遗迹在数字地图上重新呼吸。

> **历史考古类 WebGIS 项目集合**  
> 📍 收集整理：2026-04-04  
> 🎯 目标：收集全球历史、考古、文化遗产相关的 WebGIS 开源项目和在线资源

---

## 📖 项目简介

本项目集合致力于收集和整理全球范围内的**历史考古类 WebGIS 开源项目**，涵盖从古代文明重建到现代文化遗产保护的各类应用。无论你是：

- 🎓 **学术研究者** - 寻找考古数据可视化工具
- 🏛️ **博物馆/档案馆** - 需要历史地图数字化方案
- 💻 **开发者** - 寻找开源 GIS 项目参考
- 🇨🇳 **中国文化爱好者** - 探索中国历史地图资源
- 🌍 **历史爱好者** - 发现交互式历史地图

这里都有适合你的资源！

### 运行不同类型的项目

#### 1. HTML/Leaflet 项目（直接打开）
```bash
cd awesome-historical-maps
# 直接打开 index.html 或使用本地服务器
python -m http.server 8000
```

#### 2. Python/Django 项目
```bash
cd paleolithic-ruins-map
pip install -r requirements.txt
python manage.py migrate
python manage.py runserver
```

#### 3. Vue/React 项目
```bash
cd ChinaVis
npm install
npm run serve
```

#### 4. Ruby on Rails 项目（NYPL工具）
```bash
cd nypl-warper
bundle install
rake db:migrate
rails server
```

#### 5. R 语言项目
```bash
# 在 R 控制台中
install.packages("rnaturalearth")
library(rnaturalearth)
```
